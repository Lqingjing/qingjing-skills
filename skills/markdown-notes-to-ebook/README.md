# Markdown 笔记转离线电子书

将按章、页、条目编排的一篇 Markdown 转成单文件 HTML。打开后可用折叠目录翻页、搜索正文，在条目旁添加书签、重点和短批注。

## 从零开始

准备 Python 3 和可打开本地 HTML 的浏览器。本候选包用 Python 3.12 和桌面 Edge 验收，构建只用 Python 标准库。将候选包复制到可写目录，在终端进入含 SKILL.md 的目录。若系统使用 python3 命令，将下方的 python 换成 python3。

```text
python --version
python scripts/build_ebook.py --source demo/demo_notes.md --check
python scripts/build_ebook.py --source demo/demo_notes.md --output demo/demo_ebook.html --title "微型阳台观测手册" --build
```

用浏览器打开 demo/demo_ebook.html。也可以直接打开包内预生成的演示。点击“开始阅读”，用目录进入“晨间检查”，或搜索“露珠”。进入“露珠图谱”后，点星标、重点或批注。试自己的资料时，把源路径和输出路径换成自己的文件。含空格的路径用引号包住。同一路径构建会更新该 HTML。

## 输入和离线范围

以 UTF-8 无 BOM 保存文件。行首的 #、##、### 分别表示章、页、条目，井号后留空格。全书页名及条目名各自要生成唯一锚点，大小写、空格和标点差异也可能碰撞。冲突会在写输出前报出。正文可用星号粗斜体、反引号代码、简单引用、管道表格和单层列表。完整支持范围及其他调用方式见 [SKILL.md](SKILL.md)。

阅读器的样式和脚本内联，无需服务器或 CDN。演示不加载外部素材。自己的图片沿用 Markdown 中的地址，网络图片需要联网，相对图片路径以输出 HTML 所在目录为基准。窄屏布局可折叠目录，本地文件打开及存储支持随浏览器变化。

请使用可信的 Markdown。转换器尚未完成不可信输入的安全审计。--exclude-pattern 是按二级标题匹配的小节筛选，不是可靠的隐私清理机制，发布前仍须检查实际成品。

## 备份和恢复阅读数据

浏览器允许本地 HTML 使用 localStorage 时，可保存书签、重点、短注和最后阅读页。点顶部“数据”→“导出备份”，按书保留 JSON；恢复时在同一本书中点“导入备份”并选择对应文件。通用阅读器使用固定存储键，导入前先备份当前数据并核对备份来源。

同一浏览器环境中，用原路径重建且目标标题锚点保持稳定时，旧标记可继续定位。改名、删除标题、搬动文件或清理浏览器存储后，定位和数据可用性取决于锚点与浏览器。继续阅读只记录到页。
