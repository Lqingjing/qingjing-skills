# Markdown 笔记转单文件交互教辅技能 (Markdown Notes to E-Book)

本技能帮助用户把按章、页、条目组织的一篇 Markdown 笔记编译为无需服务器的单文件 HTML 阅读器。

## 笔记格式规范
使用以下标题组织笔记。页标题和条目标题各自在全书范围内须生成唯一锚点，大小写、空格和标点差异也可能产生冲突。
* `# 一级标题`：代表全书的顶层大章节（例如：`# 第一章 计算机核心基础`）；
* `## 二级标题`：代表一个独立的阅读页面（例如：`## 第一节 并发与锁机制`）；
* `### 三级标题`：代表页面内的具体知识卡片/词条（例如：`### 互斥锁与临界区`）；
* 正文支持星号粗体和斜体、反引号行内代码、三反引号代码块、单行引用、简单管道表格及单层有序和无序列表。

## 触发与调用方式

在终端中执行编译脚本（仅依赖 Python 3 标准库，零外部包安装）：

```bash
# 1. 解析统计与锚点检查（Dry-run，不写文件）
python scripts/build_ebook.py --source <你的笔记.md> --check

# 2. 正式编译为单文件 HTML
python scripts/build_ebook.py --source <你的笔记.md> --output <输出路径/教辅.html> --title "你的书名" --build
```

`--exclude-pattern` 用忽略大小写的正则匹配二级标题，跳过命中的小节及其正文。它不是可靠的隐私清理机制，发布前仍须检查实际成品。

## 产出物特点
1. **单文件零依赖**：CSS 与 JavaScript 均内联，无外链 CDN，正文与内联资源可离线阅读。图片沿用笔记中的地址，远程图片依赖网络，相对路径以输出 HTML 所在目录为基准；
2. **三端响应式**：支持窄屏折叠菜单和宽屏目录布局，设备打开本地 HTML 的能力取决于浏览器；
3. **数据隐私与持久化**：书签、重点、短批注与阅读进度依赖浏览器允许本地 HTML 使用 `localStorage`。在相同浏览器环境、输出路径和目标锚点下复用阅读记录；重命名或删除标题可能影响定位。支持按书留存 JSON 备份，导入前请核对来源。

请使用可信 Markdown。转换器尚未完成不可信输入的安全审计。首次运行和备份操作见 [README.md](README.md)。
