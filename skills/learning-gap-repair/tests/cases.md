# 固定用例与验收方式

运行前固定输入，A = 未加载目标技能，B = 原生显式加载，I = 自然语言自动选择探针。医学与时间比较为真实状态记录的脱敏改编，其余为构造测试。第二轮全部为预先固定的测试回放，不是真实用户在此次验收中的新回答；不得代用户补答模型临时提出的问题。

## 统一判据

1. **事实与归因**：机制/换算/逻辑无关键错误；正确选项中的错误理由仍需处理；只有答案时不推定唯一认知原因。
2. **最小修复**：只补当前必要关系；可选验证通常至多一个；简单查询、轻提示、明确拒绝时不强制练习，不无限追溯前置知识。
3. **验证证据**：先提出无答案的新尝试才可能收集独立证据；等待实际回复。回放未答中所问题算未验证。提示后复述、即时新应用、长期保持分开；未答不得判掌握。
4. **返回**：明确已有原目标与下一动作；无题干时请提供原题，不伪造教材页码、旧聊天或文件定位。
5. **成本**：记每轮输出字符数、等待用时与追加问题；最小案例不得增加强制轮次。复杂案例超过一小段解释可以合理，但应检查是否扩展了无关内容。
6. **范围**：不造来源，不将医学练习变成患者用药建议；不访问私人文件、不写数据库。

每个行为应对照实际输出评为通过/失败/未覆盖。本次由实施 Agent 自审，尚未取得独立人工复核结论；后续复核者应使用同一判据，发现失败保留记录。不能因为出现“已掌握”等关键词就机械判错，也不能仅凭完成状态判通过。

## 复现

使用同一模型、相同推理档位，在隔离项目新建对话。A 禁用目标技能和其他技能；B 仅启用并原生选择本技能（不是把技能文字附在普通输入里），其他条件一致。逐轮输入以下文本，保存原文，不根据 Agent 的出题临时修改回放答案。RDS 核心 A/B 各运行 5 次新对话。I-learning 与 I-negative 在仅发现本技能的会话中不显式点选，分别检查相关请求的读取事件与无关请求的不加载。

Codex 桌面/CLI 使用方式见 README。此次实际宿主配置、操作记录和原文见 results.md 与 runs.jsonl。重新运行可能产生不同措辞或不同出题，仍使用上述行为判据。

## 补充构造流程探针

以下两项在核心对照完成后加入，只测试“先等待独立尝试”和仍错时的回应，全部是构造回复，不属于真实医学记录，也不是额外的学习效果证据；不纳入原始 A/B 对照。
