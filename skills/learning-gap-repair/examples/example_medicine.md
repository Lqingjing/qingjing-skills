# 医学机制：正确选项不等于理由正确

## 来源与证据等级

来自作者现行医学学习状态记录中两条相邻的 RDS 学习条目：[0504] 第 20 题复测与纠错结果。第一条记载选 PS 缺乏正确，但理由否认肺不张/肺内液体多与 RDS 的关系；第二条记载纠正后能串出 PS 缺乏到肺泡萎陷及下游病理过程，并区分根因和后果。下一任务是病例鉴别。

公开输入是对这些事件的脱敏改编，不是原始题库题干或逐字聊天。私人文件的具体路径与行号仅保存在本地备份旁的来源定位中，不构成运行依赖。原始追问措辞、提示强度、用时及无提示延迟复测结果均 UNKNOWN；历史记录本身只能支持“纠正后通过”。

## 运行输入

第一轮和第二轮固定文本见 tests/cases.md 的 M-core。第二轮是从历史纠错结果改写的回放，用于检查 Agent 如何回应；不是验收当天真实学习者的新回答，不证明学习效果。不要根据首轮输出临时改造第二轮来迎合测验。

关键检查：是否发现理由问题；是否只补 PS → 表面张力 → 肺泡萎陷/肺不张 → 气体交换障碍与根因/后果关系；是否避免把含糊的“肺内液体多”直接等同某一机制；是否在用户要返回时停止补课。若提出新应用题而固定第二轮没有回答，应记为未完成该项验证，不能补造回答。

## 知识核验

[美国 NIH/NHLBI：RDS](https://www.nhlbi.nih.gov/health/respiratory-distress-syndrome) 与 [MedlinePlus：surfactant dysfunction](https://medlineplus.gov/genetics/condition/surfactant-dysfunction/) 支持表面活性物质、表面张力与肺泡萎陷的基础关系（核验于 2026-11-17）。公开用例只测试这段必要机制；不把完整私人笔记中的病理长链当作本版已经逐项验证的知识，也不扩展到诊疗方案。
