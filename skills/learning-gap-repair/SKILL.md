# Learning gap repair

帮助学习者补够当前任务所需的缺口，再回到原任务。依据实际对话决定帮助方式，不把每次求助变成一套测验。

## 执行

1. **抓住任务与证据。** 从用户已给内容识别原目标、卡点、作答和理由。区分可观察的错误与可能的原因：知识缺失、理解错误、提取失败、审题问题、证据不足。分类用于选择帮助方式，不必向用户展示分类表。选项正确也要看理由；单个错答案不能确定认知原因。缺少题干/理由时只说能确认的部分，最多追问一个会改变帮助方式的关键问题；不要让用户重复已提供的信息。
2. **做最小必要修复。** 换算直接纠正；术语提取优先轻提示；审题问题对齐任务要求；明确的关系误解才解释必要的因果或逻辑链。只补到足以继续当前任务，类比、公式和前置课均按需使用，不固定三段式。事实依据可信的用户材料、可核实知识或明确推导；资料含糊/冲突时说明适用条件和不确定处，不把未核实材料变成定论，不伪造页码或引用。例题、类比与真实资料分清，不自动调用私人文件。
3. **按需检查，然后等回答。** 若一次小尝试能检验关键误解是否仍在，可给一个不含答案的新判断/应用，请用户说明必要理由。不要先给答案再把复述算作独立作答。简单事实查询、已有足够表现、用户只要解释或拒绝验证时，可直接结束修复；不要强制提问。提出验证后等待实际回应，不代写用户答案。若仍错，只修相关一点，不自动追加整套练习。
4. **只判断已出现的学习证据。** 必要时用一句自然语言交代：尚未验证；提示后/刚讲过内容的复述正确；新任务即时独立应用正确；仍有缺口或证据不足。这里的“独立”指本次尝试没有暴露答案或关键解题提示，不能只凭用户说“我会了”认定。讲解后在新情境应用可以提供即时证据；相同答案的复述不等同于新情境应用。未作答不判通过，提示后正确不判无提示正确，即时表现不判长期掌握。不输出分数、掌握率或默认学习报告。
5. **回到实际主线。** 用已知任务和具体继续动作收口。未提供原题/段落时，说明回到哪个任务，并在继续确需材料时请用户贴出该部分；不要捏造原题、页码、文件锚点或跨聊天恢复能力。单独的小问题回答完即可；用户结束就停止。

## 交互与边界

- 通常直接帮助；一轮修复至多一个必要澄清、一个小验证，后续由真实表现和用户意愿决定。不要为走完流程补问问题、追问无关前置知识或反复输出状态标签。
- 用户要求只解释/继续/停止时尊重该选择，如有必要简短说明验证未完成，不阻拦返回。
- 医学等专业内容限于学习支持。涉及真实患者的诊疗决定时不要用练习流程代替专业评估或提供个体用药方案；紧急症状优先提示及时获得医疗帮助。
- 不维护数据库、复习调度或跨端状态；不承诺学习效果。无需额外脚本、依赖或私人学习系统。
