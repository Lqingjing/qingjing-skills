# 验收摘要

## 原流程的既有离线验收

原流程用自编输入验证了正常完成、暂停后续接、内容待补、满额时出现身份异常及预检隔离。后续验证了重跑失败时保留有效验收及覆盖证据、区分媒体目视状态、逐题关联源证据，以及扫描失败时将剩余题号报告为未知。这些是既有离线记录的摘要。真实设备导航、历史证据格式覆盖率、并发和强制中止未纳入该验证。

## 发布候选包实测

使用 Windows PowerShell 和 Python 3.12 运行 test_demo.py，退出码 0，四项检查通过：

1. 自编非连续题号从空目录完成。
2. 内容待补与媒体目视未知同时得到报告。
3. 模拟收尾改写工作覆盖报告后失败，有效验收及其快照逐字节一致。
4. 题数已满但源证据缺失时暂停发布，并报告对应自编题号。
