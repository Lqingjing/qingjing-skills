# 依赖与发布边界

演示使用 Windows PowerShell 5.1 与 PATH 中的 Python 3.12。Python 脚本只用标准库。运行无需联网、安装 Python 包或配置账号。实测环境为 Windows PowerShell 5.1 与 Python 3.12.10。

原私有流程使用 Android 应用、BlueStacks 及其 ADB，部分章节的收尾脚本可选用 Pillow 解码图片。本候选包以自编适配脚本和虚构 XML 格式演示验收流程，不包含这些运行组件。真实应用自动化、内容获取和再分发的权限需按适用的平台协议或平台授权另行确认。
