# Markdown 笔记转离线电子书

长笔记需要反复查阅时，可以把滚动浏览变成按目录翻页、按关键词查找。这个工具把一篇按章、页、条目编排的 Markdown 生成一个可以在浏览器中打开的 HTML 文件。

**你提供一篇笔记。** 用 UTF-8 无 BOM 保存，行首用 #、##、### 区分章、页和条目。页名和条目名需分别生成全书唯一的锚点。示例、构建命令与安装说明见 [Skill README](../../skills/markdown-notes-to-ebook/README.md)。

**你得到一本可查阅的离线电子书。** 在浏览器里按目录翻页，搜索正文，从结果跳到对应条目。与只渲染正文的 Markdown 查看方式相比，这个 HTML 还提供条目级书签、重点和短批注，可用 JSON 导出和恢复阅读记录。

**打开示例。** [微型阳台观测手册](../../skills/markdown-notes-to-ebook/demo/demo_ebook.html)是自编演示。试着在目录打开“晨间检查”，搜索“露珠”，再给“露珠图谱”加星标和一条短注。

构建使用 Python 3 标准库。桌面 Edge 已验证断网阅读、搜索、标记、JSON 恢复，以及前插异名小节后同路径重建的旧标记定位。阅读器面向可信且符合结构规范的 Markdown。外部图片沿用原地址，脱离原地址后可能无法显示。标记保存与定位依赖浏览器环境和稳定锚点。任意 Markdown 的安全性和兼容性均未获承诺。继续阅读记录到页，手机和平板的本地文件及存储行为需按设备验证。
