# 85 秒实操演示（可剪辑脚本）

用候选包副本，保持演示输出路径相同。录制时使用独立浏览器会话，避免操作日常数据。演示只使用自编《微型阳台观测手册》。

| 时间 | 画面与操作 | 口播 |
| --- | --- | --- |
| 00–10 秒 | 打开 demo/demo_notes.md，依次圈出 # 微型阳台观测手册、## 晨间检查、### 露珠图谱。 | “把按章、页、条目写的一篇 Markdown，变成能离线查阅的电子书。” |
| 10–24 秒 | 在含 SKILL.md 的目录执行下方两条命令。停在通过提示，再打开生成的 HTML。 | “先检查结构统计和锚点，再生成一个 HTML。构建只用 Python 标准库。” |
| 24–44 秒 | 切至离线浏览器。开始阅读，从目录进入“晨间检查”，搜索“露珠”并打开结果。加星标、重点和短注，再打开书签列表。 | “目录和搜索都能找到露珠图谱。我给它加个书签，写一句明早要看的内容。” |
| 44–59 秒 | 从“数据”导出 JSON。在隔离会话清除本次数据并重新打开同一文件，再导入刚才的 JSON。展示书签和短注恢复。保留操作结果，文件选择过程可跳剪。 | “阅读记录存在浏览器里，我可以导出 JSON，再导回来恢复。” |
| 59–78 秒 | 在“晨间检查”前插入下方异名小节，同路径重建。重新加载，点击旧书签，短注仍在“露珠图谱”。 | “前面多了一页，原条目锚点没变，所以旧书签还是回到露珠图谱。” |
| 78–85 秒 | 停在真实批注画面，给出 README 入口。 | “可以按 README 用自己的可信笔记试。外部图片和标记保存都有各自的条件。” |

## 实际命令

```text
python scripts/build_ebook.py --source demo/demo_notes.md --check
python scripts/build_ebook.py --source demo/demo_notes.md --output demo/demo_ebook.html --title "微型阳台观测手册" --build
```

在演示副本中，把以下内容插到原“晨间检查”之前。重建时复用上面的第二条命令。

```markdown
## 新增巡查

### 花盆间距

记录两个花盆之间的空隙。
```
