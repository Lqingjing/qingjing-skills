# 公开版脱敏说明

本目录是医学四文件与 v0.2 试跑规则的**公开设计快照**。目标是保留规则结构、判断边界和演进状态，同时移除个人信息、本地路径、课程/平台品牌和不宜公开的学习记录。

## 处理类别

| 类别 | 处理方式 |
|---|---|
| 本地绝对路径与目录名 | 替换为通用目录名，如“学习成果”“原始资料库”“医学学习进度与复习中心” |
| 课程、平台、教师品牌 | 替换为角色名，如“考研主课”“本科主课”“补充来源 A/B”“学校课程平台”“外部题库平台”“教材配套题库” |
| 具体课程版本与年度 | 替换为“当前版/旧版”或省略 |
| 个人学习记录 | 删除日期、分数、题号、正确率、具体章节进度、个人错题等 |
| 学校与考试信息 | 只保留“学校资料/阶段考试/期末”等一般类别，不保留学校名、班级、考试日期 |
| 第三方内容 | 不收录教材正文、讲义、PPT、题库原题、题目解析或笔记原文 |

## 语义保持

- 四份规则的规范语句、触发条件、退出条件和状态分工保持不变；来源名称与本地课程/进度信息被替换或省略。
- v0.2 试跑规则原文未改，并在 `trial/README.md` 增加临时性质说明。
- 被删除或概括的局部，主要是本地课程版本、章节进度和个人案例；不改变规则的设计意图。
- 《医学学习学科适配规则》的本地课程版本、章节进度和过渡状态被概括为一般规则；其余三份以名称/路径替换为主。它不是逐字快照，逐项差异见本地 diff。
- 公开版在四份规则顶部各加了一行“公开快照”说明；这是公开框架说明，不是新规则。

## 逐项对照

维护者在本地保留：

- 原文件副本；
- 每份公开文件与原文件的 unified diff；
- 文件级 SHA-256 对照表。

这些材料不随公开仓库发布，以免再次暴露原姓名、路径或学习记录。需要核对某一条改动时，可按文件与行号对照本地 diff；公开仓库只保留本说明和脱敏后的正文。

## 未包含的内容

- 原始教材、课程讲稿、学校 PPT、题库与题目原文；
- 个人正式笔记、错题、作答记录、分数、复习日期；
- 私人学习系统的运行数据、数据库、索引或工具配置；
- 任何第三方课程的完整文本或可替代原课程的整理稿。

## 发现残留信息

如果读者发现仍可能识别个人、学校或第三方来源的残留信息，请开 issue 指出文件与行号；维护者会先核对本地 diff，再决定是概括、删除还是保留。
