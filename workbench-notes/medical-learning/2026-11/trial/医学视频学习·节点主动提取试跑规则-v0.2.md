## 0. 本规则性质

本规则仅用于真实课程试跑，目的不是一次制定最终全科规则，而是验证：

1. 节点应该切多大；
2. 什么时候暂停视频最合适；
3. 节点后的首次提取应该多重；
4. 学过的节点怎样低成本反复回来；
5. 整套流程是否促进理解和记忆，而没有明显拖慢学习。

试跑期间不得因为局部不完美频繁修改规则。流程问题先记录，完成本次完整学习后统一复盘；明显阻断学习的严重问题允许当场调整。知识错误和错误反馈必须及时纠正，不受“不即时改规则”限制。

## 一、总目标

节点存在的根本目的只有一个：

> 把医学知识变成可以反复主动提取的学习单位，通过多次重新调用逐渐真正掌握。

节点不是为了整理目录、制作更漂亮的笔记、第一次就全部背会，或每个细节都当场记牢。

## 二、一轮学习目标

一轮学习的首要目标是：

> 学懂核心知识，并开始建立初始知识结构。

要求核心机制能够初步解释、重要关系能够说明、主要判断路径基本建立，并至少发生一次主动提取；按照知识类型判断，不强迫纯记忆内容解释机制。

不要求第一次学习后完整背出全部内容，不要求所有数字、细节、次要表现一次记牢，也不要求达到长期稳定记忆后才能继续。

> 首次提取成功，说明学习者在当前提示条件下，能够初步重建核心内容；理解是否稳固，还需要后续间隔提取验证。

刚听完能够复述仍可能依赖短时保留或老师措辞。机制、判断类节点有疑点时，可以用一个很小的条件变化检查理解，不必每个节点增加一套题。首次提取成功不代表已经长期掌握。

## 三、节点定义

一个节点是：

> 一个以后值得被反复重新调用的相对完整认知单元。

节点大小服从课程内容，不机械统一。可以是一条完整机制链、一个分类体系、一个诊断判断、一组临床表现、一个治疗决策、一个神经定位过程、一个操作流程，或一套需要整体记忆的规律或数值。

## 四、节点与卡点分开

节点回答：“以后我要反复提取什么？”

卡点回答：“视频看到哪里应该暂停并进行第一次提取？”

两者通常对应，但不要求一一对应。如果几个小节点高度依赖，必须全部听完才能形成完整理解，可以连续学习多个节点，设置一个共同卡点，一起进行首次提取。

禁止为了“一节点一问”把完整因果链人为切碎。

## 五、卡点设置标准

优先在以下位置设置卡点：

1. 一个相对完整机制讲完；
2. 一个分类或判断框架讲完；
3. 一个诊断／治疗逻辑讲完；
4. 一个知识结构已足够独立，可以尝试从脑中重新建立；
5. 后续继续输入可能开始覆盖当前内容。

不要因为换了一张 PPT、换了一个小标题，或老师说完一句结论，就机械设置卡点。

实际划分时，AI先依据当前准备学习的一段课程确定候选节点和自然卡点，提前给出各节点的停止位置和一个主要提取任务，不要求学习者临时设计问题或判断考查范围，也不必预先规划整章。停止位置使用已核实的课程标题、讲义边界或时间点，不猜测视频停点。一个任务可以包含必要的多个要点，但不拆成一串必须逐项通过的小问题，不提前给答案或完整答案框架。

## 六、R0：节点首次主动提取

到达卡点后停止视频，暂时遮住讲义、笔记和含答案的画面，进行第一次主动提取。

R0目的不是检查“我已经背会了吗？”，而是检查：

> 我刚才是否初步理解，并且能不能开始从自己的脑中重建它？

R0提供当前表现的初步证据，不单凭当场表现断言理解建构已经完成。

课中R0定位为轻量主动提取兼理解检查：学习者先尝试，AI快速核验，不自动计为当前学习单元的首次正式主动提取已完成。立刻提取，但不要求立刻学牢。提取与快速反馈通常约1—3分钟作为试跑参考，不设最低时长或硬性计时，也不因超时自动判定失败。

## 七、R0提取方式

采用适合该知识类型的最低必要提示量提取，不强制所有节点都完整自由复述。

AI按第五节提前明确任务和范围。到达节点后，学习者遮住材料，自行口述或回答，再将回答交给AI作一次快速核验；不要求学习者先自行判断是否正确，也不要求第一次完整讲出机制。只记得部分关系或能指出断点，同样作为本次实际提取证据。

AI只简短确认实际说对的内容、必要缺口或错误，按第八节决定继续、标记或最小纠正，并提醒下一停止位置。不默认追加详细评价、完整标准答案、逐项追问和整节点再测。学习者不确定自己答得是否正确时，可以直接要求核验，不必先判断是否属于关键错误。

完全说不出时，先用一个小提示区分提取困难与理解问题，再决定是否补讲；不直接把未说出判为不理解。例如机制型可以先问：“这个因素为什么会导致这个结果？请把中间过程串起来。”不宜起手就列出全部中间环节供逐项填空。提示情况与首次独立表现分开记录。

能够大致重建只作为继续课程的条件，不等于整节点已经全面验证或长期掌握。未交给AI的自行提取不记为AI核验通过；AI也不能因为答对一部分就宣布整个节点通过。

下列框架主要用于AI组织任务和核验，不必全部提前展示，也不意味着每次都必须逐项追问：

| 知识类型 | 适合的重建内容 |
|---|---|
| 机制型 | 原因 → 过程 → 结果 → 调节关系 |
| 分类／标准型 | 分类依据 → 各类特点 → 区别和边界 |
| 临床型 | 核心表现 → 为什么出现 → 怎样识别 |
| 诊断／鉴别型 | 线索 → 判断 → 排除 → 结论 |
| 治疗决策型 | 什么时候处理 → 为什么 → 怎样处理 → 条件改变后怎么办 |
| 神经定位型 | 表现 → 受损结构 → 病变部位；必要时反向：部位 → 应出现什么表现 |
| 流程／操作型 | 顺序 → 关键步骤 → 重要注意点 |
| 单纯记忆型 | 项目回忆、表格重建、正向或反向提取；不强行追问“为什么” |

提示后答对可以继续学习，但应与独立答出区别记录，不需要因此反复重考。

## 八、R0判定

R0不要求答案完整无缺。按照知识类型分三类处理；“想不起来”不能直接等同于“不理解”，说得流畅也不能替代结构正确。

### A. 当前核心要求初步达到

对于机制、判断类节点，核心机制能自己解释，主要结构基本正确，只漏少量非核心细节。对于纯记忆类节点，按当前主要提取任务检查关键项目及关系，不以能否解释机制判定理解。

处理：简短确认，记录本次核心内容已初步重建及必要提示情况，继续学习，后续再验证；不必把所有次要遗漏补讲一遍，不能因为非核心细节漏掉而长期卡住。

数字、条件或看似次要的项目不一定是可后延细节。如果某个阈值、单位或适用条件决定判断结果，它就是该节点的核心。具体以当前课程和明确学习目标为准，不由AI随意加码。

### B. 核心内容调用不稳或结构模糊

表现可能包括：知道结论但讲不清为什么、因果关系混乱、判断依据混乱、需要大量提示，或纯记忆节点的关键项目暂时提取不出。

处理：先区分提取困难与理解问题。普通遗忘、部分模糊或纯记忆项目暂时想不起，且不阻断后续理解时，必要时给一个小提示，标记“?”及具体位置，继续课程，留到课后或延迟提取处理；不默认追加讲解和立即复测。纯记忆内容忘了几项，不直接归为“根本没有理解”。已发现的概念错误应及时作最小纠正，不因后延而保留错误结论。

### C. 核心理解存在明显问题

表现包括无法建立核心结构、重要概念理解错误。若后续学习依赖这一知识，继续可能产生明显障碍。

处理：已发现的知识错误及时作最小纠正；核心知识完全未理解且为后续必要前提时，立即回看对应片段或调用AI作最小补讲，只修复阻塞后续的理解断点。对已纠正的关键缺口，用一次简短、自行重建关键关系的尝试确认，不重新运行整个节点的完整R0。核心因果方向仍错时不能判定通过。

### B／C共同的退出条件

普通模糊项可直接后延，不把“补充后再测一次”设为所有B类项目的继续条件。对已经实施的关键纠错，保留当次最小再提取；一次确认后仍未解决，再判断是否阻断后续学习：

- 不阻断：标记待解决并继续，在后续复测中回来。
- 确实阻断：处理必要前置知识，或暂停这条依赖链；不强行沿依赖链推进。

不得无限重复同一道提取，也不得把未解决标为通过。核心逻辑初步建立后继续，不等待完美掌握。

## 九、隐藏覆盖核验

下列覆盖核验主要用于课后正式主动提取。课中R0不逐项追齐遗漏；AI快速核验只围绕当前主要提取任务、实际回答中的错误和阻塞性理解断点。核验范围仍受来源限制，优先级为：

1. 本次主课明确讲过的重要内容；
2. 当前明确考试目标必须掌握、且已有可靠资料支持的核心内容；
3. 用户此前做题或提取已暴露的真实缺口。

禁止因为AI知道更多，就自动把额外医学知识加入当前节点要求。额外内容没有明确必要时后延。

## 十、定向追问

课中R0不因“重要内容没说全”或“部分模糊”自动追问，按第八节决定继续、标记或最小纠错。必要追问只用于辨别提取困难与理解问题、澄清实际回答或确认关键纠错，不扩展为整节点复测。课后正式提取再定向检查重要遗漏和节点连接，不要求每个节点重新完整复述。

不机械要求每节点完成固定“四问”“五问”。追问以足够确认当前理解、但不把节点变成一场小考试为准。

## 十一、滚动提取

节点学习完后不能永久退出。试跑采用三层滚动：

### R0：即时提取

节点或节点组学习结束后进行，检查能否初步理解并重建核心结构，不代表长期掌握。

**与单元正式提取的衔接：**一个相对完整的当前学习单元主体完成后，按现行执行协议进行一次正式主动提取，不机械绑定视频文件结尾。先重建整体结构与节点连接，再检查课中未覆盖、依赖提示或仍模糊的关键内容；课中真实作答保留为证据，不把所有节点原样重考一遍。明确错误及时纠正，已纠正关键缺口保留当次再提取；非阻塞的未稳项记录后进入后续复测，不以当天全部稳定作为结束条件。正式提取不替代延迟保持检验，也不改变现有课内题、真实题源及正式验证要求。

### R1：本次学习内快速回滚

完成一个自然小节后，抽取1～2个旧节点，优先薄弱点。只作快速调用，不重新教学，不要求完整复述；能够调用就立即继续。若与单元正式提取在同一边界发生，合并完成，不重复抽取同一任务。

例如：“节点A的核心链条？”合理思考后答出也算真实提取，不以反应快作为唯一标准。卡住时简短纠错并留下后续复测，不展开整节点重教。

### R2：后续间隔提取

当天稍后、次日或后续学习阶段再次出现。默认在下次学习开始时，用一个短时段抽查旧节点，重点放在之前卡住的、核心节点、易混内容和已经开始遗忘的内容，也抽查少量此前独立答对的节点。

当次未覆盖的节点保留到后续，避免每次清空全部积压。目标不是重做整章考试，而是让旧知识反复被激活。

延迟提取中能够独立调用的内容快速通过；模糊或失败时先区分遗忘与理解问题，再决定提示、回查或深入加工，不把一次失败自动升级为长时间重教。

上述触发方式与抽取数量是本次试跑参数，不是研究确定的最优次数。试跑期间先保持稳定，流程问题统一复盘。

## 十二、暂不机械规定提取次数

不规定每个节点必须提取6次、8次或其他固定次数。“二轮前已经提取6～8次很好”作为学习方向参考，不作为机械完成指标。

真正目标是在进入二轮和大量做题前，核心知识经历过多次真实重新调用，而不是只在第一次学习时见过。

## 十三、二轮暂不提前混入一轮

一轮阶段：理解＋节点提取＋低成本滚动。

二轮再逐渐提高：真题／病例／综合判断 → 暴露缺口 → 回讲义 → 重新理解 → 再提取。

不要为了追求最终完整体系，把二轮所有任务提前塞进首次学习。为核验当前理解而使用一个小条件变化，不等于提前开展整套综合训练。

## 十四、前台尽量轻

学习时只展示当前看到哪里、下一个卡点、当前主要理解目标、到卡点后的主动提取、必要纠错，以及当前需回滚的少量旧节点。

不要在学习过程中展示大量节点字段、数据库状态、来源表或复杂复习统计。后台记录服从学习效率。

AI从实际过程轻量记录独立答出／提示后答出／待解决等必要证据；无法观察的事实由用户补充或标记未知，不虚构学习结果或耗时。

## 十五、试跑期间只记录流程问题，不即时改规则

出现卡点太密或太疏、提取过长、R0变成背诵、暂停破坏理解、旧节点回来太多、AI追问过度、节点不值得单独提取等问题时，记录：

> 【试跑问题】具体发生了什么，以及对学习的影响。

继续完成本次学习。只有明显阻断学习的严重问题才当场调整，并简要记录调整原因。

“不即时改规则”仅指流程规则；已发现的概念错误、医学知识错误或AI错误反馈应当场纠正。

## 十六、一次试跑结束后只复盘五件事

1. **卡点密度：**是否频繁打断理解，或连续输入太久？
2. **节点粒度：**是否切得过碎，或大到无法提取？
3. **R0强度：**是否在检测理解，还是已经变成要求背诵？
4. **滚动成本：**旧节点回来是否足够快速，是否明显拖慢新课？
5. **真实学习效果：**与以前连续看视频相比，是否更能发现“自以为懂”，是否更容易记住、更能连接知识，并保持合理学习进度？

为这五项复盘补充三项简单证据，不额外建立复杂统计：

- 本次实际推进的视频内容时长；
- 提取、纠错和回滚额外耗时；
- 次日抽查时，哪些能独立答出、哪些仍需提示、哪些尚未解决。

当堂结束评估流程是否顺畅；记忆效果至少留到次日抽查后作初步判断。一次试跑与以往学习的比较，只提供继续试验的依据，不足以证明长期效果或严格的因果优势。

## 十七、试跑阶段禁止事项

1. 因一次答不完整就判定节点失败；
2. 要求所有细节第一次学完即背会；
3. 每个小标题都设置提取；
4. 每轮都完整复述全部节点；
5. AI不断扩充老师未讲、也无明确必要的知识；
6. 一边学习一边反复修改系统规则；
7. 为记录提取次数增加大量操作负担；
8. 因某节点没有完美掌握而阻止课程继续推进；
9. 把提示后答出记录为独立答出，或把当场顺畅复述认定为长期掌握；
10. 以“不改规则”为理由推迟纠正知识错误，或把未解决的核心问题标为通过。

## 十八、当前试跑成功标准

一次试跑不要求证明能够永久记住。只需获得初步证据：

> 相比以往单纯连续看视频的体验，本流程更有助于暴露理解缺口，并能以可接受的时间成本让旧知识反复重新出现；次日抽查进一步检验能否独立重建核心内容。

若达到这一点，再讨论正式多轮复习机制；不因一次试跑成功自动升级为全科长期规则。
