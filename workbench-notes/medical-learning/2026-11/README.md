# 医学 AI 学习工作台｜2026-11 设计快照

> **状态：设计快照（2026-11）。** 这不是可安装的 Agent Skill，不是已验证的学习产品，也不是一套要求读者照做的医学课程。
>
> **位置：** `workbench-notes/medical-learning/2026-11/`，与仓库的 `skills/`、`demos/` 分开。

## 这是什么

这是 2026 年 11 月对“医学视频学习 + AI 辅助 + 主动提取”工作台的一次阶段性整理。公开的是：

- 四份规则各自负责什么、不负责什么；
- 工作台如何划分知识、状态、证据和题源；
- 已经出现过哪些真实学习片段；
- 哪些东西还没有验证。

不公开的是：私人学习系统的运行数据、原始课程资料、题库、正式笔记和个人学习记录。

**适合谁读：** 做 AI 教育/学习工具的人；想把聊天带学变成可维护系统的医学学习者；想看清“设计假设”和“效果证据”区别的读者。

**不适合谁：** 想找可安装 Skill、医学课程、题库或“提分效果证明”的读者。

## 为什么做这个

医学学习里同时存在几种压力：

1. 视频和讲义是连续输入，但考试要求的是能主动重建、能做题、能迁移。
2. 主课、学校课程、教材、补充课和题库各自有用，职责却经常混在一起。
3. 笔记、题目、错题和复习各自生长，容易出现第二套“真相”。
4. AI 每次对话都从零开始，不知道学习者学到哪、哪条证据可靠。
5. 一次答对或答错容易被过度解释：提示后答出被记成“会了”，一次小测被记成“整章掌握”。

这个工作台的目标不是让 AI 替学习者学习，而是把“教、练、记、复”分开，让每个结论都能回到来源和证据。

## 工作台架构

```text
输入层：课程 / 教材 / 学校资料 / 真实题
        ↓
规则层：执行协议 + 学科适配 + 笔记规范 + 方法库
        ↓
状态层：医学学习进度与复习中心（唯一动态状态）
        ↓
知识层：正式笔记（唯一知识资产）
        ↓
证据层：R0 / 单元正式提取 / R1 / R2 / 真实题
        ↓
输出层：下一入口、复测队列、错因与高风险点
```

### 五个设计决定

1. **单一权威。** 知识正文只放正式笔记；动态状态只放医学学习进度与复习中心；原始资料和题库留在资料库。聊天只是执行工作区，不是长期权威。
2. **三态分离。** 知识资产状态（笔记是否写入）、当前学习阶段（本人学到哪）、保持/复测状态（能否跨时段独立提取）必须分开，不能用“学完了”同时代表三者。
3. **教与考分离。** 教学中的预测、追问、提示和短检查是教学工具，不等于正式主动提取；课中 R0、单元正式提取、R1、R2 和真实题各自留下不同证据。
4. **来源按职责，不按排名。** 教材负责事实和边界；主课负责完整讲解和课程结构；补充来源负责定点补讲；学校资料决定学校考试边界；题库负责验证。来源冲突必须显式处理。
5. **前台尽量轻。** 学习时只显示当前位置、下一个卡点、当前任务和必要纠错；覆盖矩阵、状态码和后台记录不倾倒给学习者。

### 证据阶梯

| 事件 | 回答什么 | 不回答什么 |
|---|---|---|
| 课中 R0 | 这个节点刚才是否初步理解，能否开始重建 | 整个单元是否学完 |
| 单元正式提取 | 单元整体结构和节点连接是否建立 | 长期保持或真实题应用 |
| R1 | 本次学习内的旧点能否快速调用 | 跨时段保持 |
| R2 | 隔一段时间能否不看材料独立说出 | 整章重新掌握 |
| 真实题 | 能否在陌生题里应用 | 是否理解机制（需另行解释） |

这条阶梯的核心不是“多考几次”，而是**不同时间、不同提示条件、不同任务类型分别记证据**。提示后答出、次日独立答出、真实题答对，不能互相替代。

## 已有实践

以下只写设计观察，不含个人分数、日期、题号或学校信息。

- **短答正确，不等于应用题正确。** 真实学习中出现过“能说出两个药名，但在长期控制题里选错”的情况；短回忆和应用判断测到的是不同能力。
- **连续补测会打断单元。** 真实学习中出现过题目越过当前教学范围、连续追问打断推进的情况；后来调整为自然卡点、节间短回忆、整组完成后集中做题。
- **关键错误纠正后，当次再提取可以通过。** 但这只说明“撤掉答案后这次能重建”，不等于次日仍能独立，也不等于长期保持。
- **真实题整章正确率不等于机制解释。** 题量、正确率、解析浏览和“能不能从脑中重建”是不同层证据。
- **v0.2 有片段，没有整套试跑。** 真实学习中已经出现过课中短提取、纠错后再提取、真实题和待复测片段；但没有完成同一单元从 R0 到单元正式提取、再到次日独立提取的完整记录。

这些观察支持“哪些风险真实存在”，不支持“这套方法已经优于普通学习”。

## 当前验证边界

- 没有对照实验，不能声称优于普通 AI、连续看视频或传统笔记。
- 没有完成同一单元的完整 R0 → 单元正式提取 → 次日独立链条。
- 没有系统测量实际视频时长、提取/纠错/回滚额外耗时。
- 没有 3 天/7 天保持数据，也没有跨学科、跨知识类型的泛化证据。
- 规则来自单学习者、医学场景的设计经验；其他学科、其他考试、其他 AI 宿主不能直接套用。
- AI 生成内容仍需教材和来源核验；规则存在不等于执行正确，执行一次也不等于长期有效。

## 未来方向

1. **一个单元的真实试跑。** 选一个本来就要学的视频单元，完成一次 R0、单元正式提取和次日独立提取，记录实际耗时与提示条件。
2. **轻量证据记录。** 只记时点、提示等级、本人原话摘要、结论和下一触发；不建第二套台账，不要求逐节点打分。
3. **工作台界面研究。** 把阅读、提问、提取、题目和状态写回放在同一处；这是设计方向，当前没有实现。
4. **公开/私人分层。** 公开规则、架构和脱敏案例；私人课程、题库、笔记和学习记录继续留在本地。

## 术语

- **正式笔记：** 知识资产的唯一载体；不是聊天记录，也不是第二套复习提纲。
- **动态状态：** 医学学习进度与复习中心里的学习阶段、证据、保持/复测状态和下一入口。
- **R0：** 课中节点首次主动提取，轻量，不等于单元正式提取。
- **单元正式提取：** 主体教学完成后，对整体结构和节点连接的提取。
- **R1：** 本次学习内的快速回滚，通常只抽一两个旧点。
- **R2：** 次日或后续学习阶段的间隔提取。
- **真实题：** 有明确来源的题；默认闭卷首答；教学暴露题不算陌生首答或冷测。
- **P/M/N：** 旧版内部缩写，分别偏指学习阶段、保持/复测状态、知识资产；新文档已尽量改用语义字段，读到时可把它当作旧记号。
- **thread：** 聊天执行工作区，不是长期权威存储。
